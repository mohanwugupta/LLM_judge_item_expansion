## Execution Changes

The 10-GB matrix reader uses only analysis fields and categorical repeated IDs.
Original judgment payloads stay in the immutable source CSV. Nullable ambiguity
flags preserve missingness in Parquet. Existing matrix fixtures pass.

The episode sampler uses `np.random.choice(n)` instead of materializing `range(n)`.
Regression tests verify identical episode arrays, RNG state, training metrics, and
weights. Four spawned workers run independently seeded models concurrently;
spawn-versus-serial fixture tests verify identical checkpoint weights and metrics. Numeric NumPy
embedding transport avoids requiring Torch shared-memory helpers. Worker count and
progress logging are operational settings, not changes to the model or optimizer.
CPU/BLAS thread counts are one per worker.

Bootstrap execution caches repeated seeds within a draw, while preserving the
draw's replacement multiplicities, order, and RNG consumption. Complete fixture
summaries and paired confidence intervals match the uncached implementation exactly.
No repetitions, analysis seed, CV folds, or uncertainty definitions were changed.

All new matrix and model outputs are under `ISC-CI_LLM_validation/artifacts/`.
Compatibility symlinks expose them as `artifacts/v4/matrices` and
`artifacts/v4/validation`. The fixed bank was read from its already downloaded
Git LFS object with SHA-256
`d9eecd131c55cbeccfa6159bd0eddcbe7e6f1fc366ce63eda118b79b5c4010fb`.
