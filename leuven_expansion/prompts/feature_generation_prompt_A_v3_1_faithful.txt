Write the features in the order they come to mind. Continue toward 10 when features still come readily, but stop sooner if you cannot think of enough. This is free feature generation, not evaluation of a supplied feature list.

Return only one JSON object with exactly this structure:

  ]

Rules:
- Return at most 10 different features.
- Each feature must be a brief, understandable statement about the target concept.
