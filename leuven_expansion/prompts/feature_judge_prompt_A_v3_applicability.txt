You are simulating the second stage of the Leuven semantic norming procedure: feature applicability judgments.

In the original Leuven study, participants first freely generated features for words (perceptual, functional, and background properties). The researchers then built exemplar-by-feature applicability matrices. For each matrix cell, four independent raters judged whether a given feature characterized a given exemplar by marking 1 (yes) or 0 (no).

Your task is to estimate how many of those 4 independent Leuven raters would mark this feature as characterizing the target word.

Use the scale directly:

0 = 0 of 4 raters would mark yes
1 = 1 of 4 raters would mark yes
2 = 2 of 4 raters would mark yes
3 = 3 of 4 raters would mark yes
4 = 4 of 4 raters would mark yes

A feature characterizes a word when it is a normal, ordinary, psychologically relevant property that an average person would endorse. This is not a strict truth judgment. This is not a free-production judgment. It is a Leuven applicability judgment.

Do NOT mark a feature positive merely because it is:
- technically true in a trivial or very general sense (e.g. "has atoms", "exists", "is made of matter")
- only remotely or metaphorically associated
- true only in rare or highly specific contexts
- a property virtually all objects share

DO mark a feature positive when it is:
- an ordinary, characteristic property of the word
- something typical participants would readily endorse when asked
- applicable even if participants might not have spontaneously listed it

Examples:
- dog x "has fur" -> 4 (all 4 raters would say yes; central, ordinary property)
- dog x "has kidneys" -> 0 (technically true but not a psychologically relevant characteristic)
- chair x "is used for sitting" -> 4
- chair x "has atoms" -> 0 (trivially true of everything)
- apple x "is edible" -> 4
- apple x "can be found in stores" -> 2 or 3 (true, but not highly characteristic)
- snake x "is dangerous" -> 3 (many but not all raters would endorse this)

Judge only this single target_word x feature pair. Do not infer a full feature vector. Do not consider other pairs.

Return valid JSON only. The JSON must include exactly these fields: target_word, feature_id, feature_value, confidence, ambiguous, reason.
Respond in English only. DO NOT use any non-English characters. Keep your reason to one concise sentence (maximum 150 characters).
